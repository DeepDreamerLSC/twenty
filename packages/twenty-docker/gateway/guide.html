客户管理系统管理员使用指南

面向第一次接触系统的管理员，介绍账号管理、角色权限、客户资料维护和日常安全检查。

账号与成员管理

新员工如何注册

  1. 打开登录页，选择“注册”。
  2. 输入中文或英文账号，以及 8–50 位密码。
  3. 注册成功后，员工默认加入当前工作区。
  4. 管理员进入 设置 → 成员 核对账号，并分配合适角色。

登录与改密

  • 系统使用账号和密码登录，不要求填写邮箱。
  • 首次登录后，本设备可在一定期限内免密进入。
  • 修改密码必须验证当前密码；修改成功后，历史免密会话会立即失效。
  • 如果忘记当前密码，需要联系系统维护人员进行人工重置。

角色与权限

管理员可以在 设置 → 成员 → 角色 中创建角色、设置权限，并将员工分配到对应角色。

上线前必须检查默认 Member 角色

当前默认 Member 角色权限较大，能够查看、修改和删除全部 CRM 数据。正式开放员工注册前，建议先收紧权限或建立受限角色。

Admin 管理员

拥有全部设置和数据权限。系统内置角色，不建议分配给普通员工。

普通员工

可维护客户、任务和备注，不允许修改系统设置或永久删除数据。

客服 / 顾问

可查看和更新负责的客户资料，按实际工作需要开放字段。

只读人员

只允许查询客户和业务数据，不允许新增、修改或删除。

建议遵循最小权限原则

  • 只有确实负责系统管理的人才使用 Admin。
  • 普通员工默认关闭永久删除和系统设置权限。
  • 员工离职时，及时移除或停用其成员账号。
  • 角色变更后，让员工刷新页面或重新登录。

日常客户管理

人员

记录具体客户或联系人，包括姓名、手机、微信、来源和备注。

公司

记录客户所属企业、机构或其他组织，并关联具体联系人。

商机

跟踪项目、成交机会、负责人、预计金额和当前阶段。

任务

安排回访、资料补充和后续跟进，设置负责人及截止时间。

笔记与动态

保存沟通内容、客户备注和操作轨迹，方便团队接续服务。

列表与视图

通过筛选、排序和保存视图，快速找到待跟进或重点客户。

推荐的客户录入规范

至少录入客户姓名、手机号、微信号、客户来源、负责人、首次接触时间和备注。手机号等关键字段应统一格式，避免同一客户重复建档。

管理员首次使用清单

  1. 修改自己的初始密码，并避免多人共用管理员账号。
  2. 检查当前管理员名单，只保留确实需要管理权限的人员。
  3. 创建普通员工、客服和只读角色，关闭不必要的删除权限。
  4. 检查默认 Member 角色，确定新注册员工的默认访问范围。
  5. 先录入少量测试客户，确认字段和流程后再批量导入。
  6. 约定客户录入规范、负责人分配方式和定期回访流程。
  7. 定期检查成员、角色和异常登录情况，并做好数据库备份。

常见问题

角色已经修改，但员工看不到新权限

请先刷新页面；如果仍未更新，让员工退出后重新登录。

员工忘记密码

当前账号不依赖真实邮箱，无法通过邮件找回。请联系系统维护人员人工重置，重置后提醒员工立即修改密码。

找不到成员或角色入口

确认当前账号拥有 Admin 权限，然后进入 设置 → 成员；角色页面位于成员页面的“角色”标签。

页面无法打开

先刷新浏览器并检查网络。如果所有人都无法访问，应由系统维护人员检查 Cloudflare 隧道和 CRM 容器健康状态。
